Glossaire Technique

Référence rapide des termes et concepts clés abordés dans ce cours.

API REST
Interface utilisant les verbes HTTP (GET, POST, PUT, DELETE) pour exposer des ressources via URLs standardisées. Retourne du JSON.
Circuit Breaker
Pattern de résilience interrompant les appels vers un service défaillant. Implémenté avec Resilience4j. Trois états : fermé (normal), ouvert (bloqué), semi-ouvert (test).
Clean Architecture
Séparation du domaine métier des détails techniques via des couches indépendantes et règles de dépendance strictes. Le domaine ne dépend de rien, tout dépend du domaine.
CQRS
Command Query Responsibility Segregation : séparation des opérations de lecture (Query) et d'écriture (Command) en deux modèles distincts, chacun optimisé pour son usage.
DTO
Data Transfer Object : objet de transport de données entre couches ou via API REST, distinct des entités de domaine. Protège le modèle interne de l'exposition externe.
Event-Driven
Paradigme où les services communiquent via événements asynchrones. Découplage total entre producteur et consommateur. Implémenté avec Apache Kafka.
gRPC
Framework d'appel de procédure à distance haute performance par Google, basé sur Protocol Buffers. Plus rapide que REST pour la communication inter-services.
HPA
Horizontal Pod Autoscaler : mécanisme Kubernetes d'ajustement automatique du nombre de pods selon la charge (CPU, mémoire, métriques custom).
IaC
Infrastructure as Code : gestion d'infrastructure via fichiers versionnés. Outils : Docker Compose, Terraform, Kubernetes YAML. Reproductible et auditable.
JWT
JSON Web Token : token signé pour authentification stateless sans session serveur. Contient les claims (identité, rôles) et une signature cryptographique.
Kafka
Plateforme de streaming d'événements distribuée Apache avec persistance durable et partitionnement. Topics, partitions, consumer groups, retention configurable.
Microservice
Service autonome responsable d'un domaine métier unique, déployable indépendamment. Possède sa propre base de données et communique via API ou événements.
Redis
Base de données clé-valeur in-memory pour cache distribué, session store ou broker de messages Pub/Sub. Latence sub-milliseconde.
SAGA Pattern
Gestion de transactions distribuées via une séquence d'étapes locales avec compensation (rollback) en cas d'échec. Alternative aux transactions distribuées classiques (2PC).
Spring Actuator
Module Spring Boot exposant des endpoints de monitoring : /health, /metrics, /prometheus, /info. Intégration native avec Prometheus et Grafana.
Stateless
Service sans état en mémoire locale. Aucune donnée de session stockée dans l'instance. Prérequis indispensable pour la scalabilité horizontale.
Use Case
Classe de la couche application encapsulant une action métier unique et atomique. Orchestre les appels au domaine et à l'infrastructure. Exemple : CreateTaskUseCase.
WebClient
Client HTTP réactif non-bloquant de Spring WebFlux, remplacement moderne de RestTemplate. Supporte les flux réactifs (Mono, Flux) et le streaming.
