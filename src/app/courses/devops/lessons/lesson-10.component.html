  │              Prometheus Server                │

    ┌──────▼──────┐               ┌──────▼──────┐

    └─────────────┘

Prometheus fonctionne en pull : il interroge (scrape) les endpoints des applications à intervalle régulier.

Instrumenter Spring Boot avec Micrometer

pom.xml - dépendances
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-actuator</artifactId>
</dependency>
<dependency>
    <groupId>io.micrometer</groupId>
    <artifactId>micrometer-registry-prometheus</artifactId>
</dependency>
application.yml
management:
  endpoints:
    web:
      exposure:
        include: health, info, prometheus, metrics
  metrics:
    tags:
      application: my-api

Métriques custom

OrderService.java
@Service
public class OrderService {{ '{' }}

    private final Counter ordersCounter;
    private final Timer orderProcessingTimer;

    public OrderService(MeterRegistry registry) {{ '{' }}
        this.ordersCounter = Counter.builder("app_orders_total")
            .description("Total des commandes traitées")
            .tag("service", "order-service")
            .register(registry);

        this.orderProcessingTimer = Timer.builder("app_order_duration_seconds")
            .description("Durée de traitement d'une commande")
            .register(registry);
    {{ '}' }}

    public OrderResponse processOrder(OrderRequest request) {{ '{' }}
        return orderProcessingTimer.record(() -> {{ '{' }}
            ordersCounter.increment();
            // Logique métier...
            return new OrderResponse(/* ... */);
        {{ '}' }});
    {{ '}' }}
{{ '}' }}

Déployer Prometheus sur K8s

bash - via Helm
# Ajouter le repo Helm
helm repo add prometheus-community https://prometheus-community.github.io/helm-charts
helm repo update

# Installer le stack complet (Prometheus + Grafana + Alertmanager)
helm install monitoring prometheus-community/kube-prometheus-stack \
  --namespace monitoring \
  --create-namespace \
  --set grafana.adminPassword='ChangeMe123!'
servicemonitor.yaml - Scraper Spring Boot
apiVersion: monitoring.coreos.com/v1
kind: ServiceMonitor
metadata:
  name: api-backend-monitor
  namespace: monitoring
spec:
  selector:
    matchLabels:
      app: api-backend
  namespaceSelector:
    matchNames:
      - production
  endpoints:
    - port: http
      path: /actuator/prometheus
      interval: 15s

PromQL - Requêtes essentielles

PromQL
# Taux de requêtes HTTP par seconde (5 dernières minutes)
rate(http_server_requests_seconds_count[5m])

# Latence P99
histogram_quantile(0.99, rate(http_server_requests_seconds_bucket[5m]))

# Taux d'erreurs 5xx
sum(rate(http_server_requests_seconds_count{{ '{' }}status=~"5.."{{ '}' }}[5m]))
  / sum(rate(http_server_requests_seconds_count[5m]))

# Utilisation mémoire JVM
jvm_memory_used_bytes{{ '{' }}area="heap"{{ '}' }}
  / jvm_memory_max_bytes{{ '{' }}area="heap"{{ '}' }}

Grafana - Dashboards

Grafana se connecte à Prometheus comme source de données et permet de créer des dashboards visuels.

Dashboards recommandés
  • JVM (Micrometer) - ID: 4701 - Mémoire, GC, threads
  • Spring Boot - ID: 12900 - HTTP, cache, DB pool
  • K8s Cluster - ID: 6417 - Nodes, pods, namespaces
  • NGINX Ingress - ID: 9614 - Trafic, latence, erreurs

Importez-les via le menu Dashboards → Import avec l'ID correspondant.
