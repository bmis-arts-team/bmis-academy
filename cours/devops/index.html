DevOps, Kubernetes & Production

Formation enterprise-grade : maîtrisez Docker, Kubernetes, CI/CD, l'observabilité et le déploiement production d'un vrai système fintech.

14 Leçons
8 Sections
50+ Manifestes YAML
K8s 1.30+ Version

Système de référence - Architecture Fintech

Stack technique déployé dans ce cours
  • Frontend : Angular (Admin & Partners), Flutter (Customer App, Delivery App)
  • Backend : Spring Boot 3.x (Monolithe Modulaire)
  • API Gateway : Entrée unique pour tous les clients
  • Base de données : PostgreSQL (primaire) + Redis (cache)
  • Paiements : MTN MoMo, Orange Money, Express Union Mobile, Stripe
  • CI/CD : GitHub Actions + Maven + Docker
  • Orchestration : Kubernetes
  • Observabilité : Prometheus, Grafana, ELK Stack
  • CDN / Edge : Distribution des assets et applications
